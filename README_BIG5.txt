Math Cube - Phase 2

本版本由 Phase 1.3 Records 基礎重新建立。原有 Normal Mode 3D 魔方玩法仍然是核心，新增功能以整合式架構加入，而不是把 1.4、1.5、1.6、1.7 的修改層層疊加。

功能包括：
- 原有 Normal Mode、關卡及 3D 魔方
- 綠色 → 藍色 → 紫色 Cyber UI
- Speed Training
- Brain Training
- 五種提示
- Combo Station 及連擊火焰
- S/A/B/C/D/E 等級
- Normal / Speed / Brain 個人紀錄
- 金蘋果、商店及收藏
- 成就
- 每日及每週挑戰
- English / 繁體中文 / 简体中文 / 日本語 / 한국어
- 同一畫面只顯示一種語言
- Smart Scroll 橫向按鈕列
- Supabase 雲端整合
- 沒有 Supabase 時使用本機資料

請保留自己的 js/config.js。部署時不要把 Supabase 私密設定放入公開程式碼。
