MATH CUBE V2 ART ASSETS

The game currently works without these files. They are optional visual assets for the modern anime-inspired presentation.

RECOMMENDED PNGS

1. hero-character.png
   Transparent PNG
   1024 x 1024 or larger
   Main Math Cube character for Home screen.
   Style: modern Japanese anime-inspired game character, youthful, energetic, clean, friendly, no text, no logo.

2. primary-student.png
   Transparent PNG
   1024 x 1024 or larger
   Younger student character used by the Primary Student hint.
   Expression: thoughtful/confident, sometimes uncertain.

3. high-school-student.png
   Transparent PNG
   1024 x 1024 or larger
   Older student character used by the High School Student hint.
   Expression: confident but not all-knowing.

4. audience.png
   Transparent PNG
   1536 x 1024 or larger
   Small group of students used by Ask an Audience.

5. home-background.png (optional)
   1920 x 1080 PNG
   Abstract futuristic anime-game background. No text.

6. cube-logo.png (optional)
   Transparent PNG, 1024 x 1024
   Math Cube logo/mark.

IMPORTANT
- Do not bake UI text into character/background images; text is localized by the web app.
- Keep character backgrounds transparent.
- The game UI does not depend on emoji artwork.
